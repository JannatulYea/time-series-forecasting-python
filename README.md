Time Series Decomposition & Forecasting

A comprehensive Time Series Analysis project exploring signal decomposition, trend/seasonality modeling, and predictive forecasting techniques in Python.

Features
Synthetic Signal Generation:Constructed additive time series models combining linear trend, sine-wave seasonality, and Gaussian noise.
Classical Forecasting:Implemented statistical forecasting using statsmodels.tsa.arima.model.ARIMA.
Regression-Based Modeling:Fitted Polynomial Features and Linear Regression models to capture complex trend dynamics.
 Built With
* Python 3
* Statsmodels (ARIMA)
* Scikit-Learn, Pandas, NumPy, Matplotlib
 Unsupervised Learning: Clustering & PCA Dimensionality Reduction

An Unsupervised Machine Learning project focused on pattern discovery, feature space reduction, and model evaluation using the Breast Cancer dataset from Scikit-Learn.

 Features
Clustering Analysis:Grouped high-dimensional data points to discover underlying feature clusters.
Dimensionality Reduction:Applied Principal Component Analysis (PCA) to compress feature space while retaining maximum variance.
Performance Benchmarking: Compared model performance and clustering accuracy before and after PCA transformation.

Built With
* Python 3
* Scikit-Learn (PCA, Clustering)
* Pandas, NumPy, Matplotlib
